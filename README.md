# Page Removed

A minimal, professional removal notice page built with vanilla HTML/CSS.

## What's here?

Simple landing page informing visitors that the website has been removed, with a link to the developer's portfolio.

## Features

- 🎨 **Glassmorphism design** — Dark gradient background with smooth animations
- 📱 **Fully responsive** — Works on mobile and desktop
- ⚡ **Zero dependencies** — Pure HTML/CSS
- ✨ **Smooth animations** — Floating icon and hover effects

## Quick Start

1. Clone/fork this repo
2. Open `index.html` in your browser
3. Or deploy to GitHub Pages

## File Structure

```
.
├── index.html    # Main page
└── README.md     # This file
```

## Customization

Edit `index.html` to change:
- Portfolio link (line ~79)
- Message text
- Colors/gradients
- Icon emoji
